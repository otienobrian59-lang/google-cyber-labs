## Notes

### 1. Security Domains
The CISSP identifies 8 security domains that provide a comprehensive framework for cybersecurity:
1. Security and Risk Management
2. Asset Security
3. Security Architecture and Engineering
4. Communication and Network Security
5. Identity and Access Management (IAM)
6. Security Assessment and Testing
7. Security Operations
8. Software Development Security

### 2. Security Frameworks and Controls
Frameworks provide a structured approach to managing risk:
- **NIST CSF (Cybersecurity Framework)**: Focuses on five core functions: *Identify, Protect, Detect, Respond, Recover*.
- **NIST RMF (Risk Management Framework)**: A 7-step process for managing security and privacy risk:
  1. **Prepare**: Essential activities to prepare the organization.
  2. **Categorize**: Categorize the system and information based on impact analysis.
  3. **Select**: Select an initial set of controls.
  4. **Implement**: Implement the controls and document deployment.
  5. **Assess**: Determine if controls are operating as intended.
  6. **Authorize**: Provide a risk-based decision to authorize system operation.
  7. **Monitor**: Continuously monitor control implementation and risks.

### 3. Security Audits
A security audit is a manual or systematic measurable technical assessment of a system or application. It ensures that an organization’s security policies are being followed.

### 4. SIEM Tools
Security Information and Event Management (SIEM) tools provide real-time analysis of security alerts:
- **Google Chronicle**: A cloud-native SIEM that allows for fast searching and analysis of massive amounts of security data.
- **Splunk**: A popular SIEM used for monitoring, searching, and analyzing machine-generated data.

### 5. Incident Response Playbooks
Playbooks are sets of instructions for responding to specific types of security incidents. They ensure a consistent and effective response to threats like malware, phishing, or unauthorized access.
